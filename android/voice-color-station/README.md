# Voice Color Station

Минимальный Android-прототип голосовой станции для LG V50S. Пока приложение
открыто на экране, оно циклически запускает системный `SpeechRecognizer`
(`ru-RU`) и ждёт триггер «Помогатор». Название цвета можно произнести в той же
фразе или отдельной следующей командой; фон всего экрана изменится, а системный
TTS озвучит подтверждение.

Примеры:

- `Помогатор, включи синий`;
- сначала `Помогатор`, затем `красный`.

Распознавание предоставляет установленный Android-сервис и может использовать
интернет. Начиная с версии 0.3.0 распознавание работает в microphone
foreground-service и продолжается после сворачивания Activity. Android
показывает постоянное уведомление «Помогатор слушает»; его действие
«Остановить» полностью прекращает службу. Повторный запуск приложения снова
включает её.

Это эксперимент непрерывного перезапуска системных recognition-сессий, а не
энергоэффективный локальный hotword. Следующий вариант должен заменить этот
участок на локальный wake-word движок, оставив UI и команды без изменений.

Поддерживаются красный, зелёный, голубой, синий, жёлтый, оранжевый,
фиолетовый, розовый, белый, серый и чёрный.

Сборка из корня проекта:

```powershell
.\scripts\build-voice-color-station.ps1
```

Сценарий ожидает OpenJDK (`javac`, `jar`, `keytool`) и Android SDK в стандартном
`%LOCALAPPDATA%\Android\Sdk` с platform/build-tools 34.0.0. Он выполняет
воспроизводимую цепочку без Gradle:

1. `aapt2 link` создаёт resources APK из `AndroidManifest.xml`;
2. `javac` компилирует все Java-файлы;
3. `jar` и `d8` создают `classes.dex`;
4. `zipalign` выравнивает APK;
5. `apksigner` подписывает и проверяет debug-сборку.

Результат появляется в
`android/voice-color-station/artifacts/voice-color-station-debug.apk`. Каталоги
`build/`, `artifacts/` и локальный debug-keystore не входят в Git.

Установка на уже авторизованный ADB-телефон:

```powershell
.\scripts\install-voice-color-station.ps1
```

Debug signing key создаётся локально в `.tools/voice-color-station/` и не
предназначен для публикации приложения.
