# LG V50S Home Server

Цель проекта — оценить возможность безопасного использования LG V50S ThinQ
(LM-V510N) как домашнего сервера с Home Assistant и сопутствующими сервисами.

## Текущее состояние

- Этап: диагностика и исследование архитектур завершены; установка ожидает
  отдельного подтверждения пользователя.
- Изменения на телефоне: не выполнялись.
- ADB: подключён и авторизован; модель подтверждена как `LM-V510N` (`mh2lm`).
- Загрузчик: система сообщает `unlocked`; Verified Boot — `orange`.
- Root/Magisk: не обнаружены.
- Штатное ядро не подходит для стандартного Docker из-за
  отсутствующих namespaces/cgroup-контроллеров и OverlayFS.
- Рекомендуемый следующий этап: не-root proof of concept в Termux/PRoot,
  без прошивки, root и модификации ядра.
- Все действия фиксируются в `WORKLOG.md`.

Подробности: `docs/architecture.md`, воспроизводимый порядок работ:
`docs/installation-plan.md`.

Сценарии, выполняемые внутри телефона, хранятся в каталоге `phone/`; каждый
этап ведёт собственный журнал в `~/setup-logs/` внутри Termux.

## Ограничения текущего этапа

До отдельного подтверждения запрещены прошивка разделов, изменение загрузчика,
factory reset, установка Magisk, модификация ядра и другие потенциально
необратимые изменения устройства.
