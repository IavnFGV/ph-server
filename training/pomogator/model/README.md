# Обученная модель POC

Модель обучена пользователем 16 октября 2026 в Google Colab на синтетических
русских Piper-примерах и данных из `pomogator.yml`.

- `pomogator.onnx` — runtime-модель openWakeWord, вход `[1, 16, 96]`, выход
  `[1, 1]`, ONNX opset 13.
- `pomogator-checkpoint.pt` — checkpoint весов для восстановления/переэкспорта.
- `training-report.txt` — независимая локальная проверка и SHA-256.

ONNX проверен `onnx.checker` и ONNX Runtime на CPU. Checkpoint проверен только
как ZIP-контейнер без десериализации; все 10 тензоров весов ONNX совпадают с
его бинарными хранилищами. Это ещё не доказательство
качества детектора: до Android-интеграции нужны тесты реальных голосов, ложных
срабатываний и пропусков. Из-за лицензий обучающих данных — только личный
некоммерческий POC.
