Следующий предлагаемый шаг — установка официального LG Universal Mobile
Driver. Это системное изменение Windows и ожидает явного согласия пользователя.

### Исключение Termux из Doze

- Перед изменением проверено: `com.termux` и `com.termux.boot` отсутствовали в
  системном device-idle whitelist.
- Первая PowerShell-команда проверки не запустилась из-за неэкранированного
  двоеточия после переменной `$p`; ADB не вызывался и телефон не изменился.
- Выполнены обратимые команды:
  `adb shell dumpsys deviceidle whitelist +com.termux` и
  `adb shell dumpsys deviceidle whitelist +com.termux.boot`.
- Android ответил `Added` для обоих пакетов; повторная проверка подтвердила их
  наличие в whitelist.
- Глобальный phantom-process monitor и другие системные настройки не менялись.

### Повторный разбор архитектуры и Docker

  границе Android Bionic/vendor ABI и Ubuntu glibc/PRoot, а не в отсутствии
  ускорителей. Практичная архитектура — Android APK/foreground worker с NNAPI
  или совместимым Qualcomm SDK, предоставляющий локальный API Linux/HA.
- Текущая публичная QAIRT-таблица не перечисляет SM8150 как актуальную mobile-
  цель; до использования прямого QNN/SNPE нужен compatibility benchmark.
  Безопасный первый прототип — малый TFLite NNAPI benchmark без root, после чего
  решать, оправдан ли отдельный Android accelerator service для голоса.
